# Eco Metrics Capstone Project

A custom MVC PHP application built for tracking ecological metrics, carbon footprint, and sustainability data.

## Requirements
- PHP 8.x
- Composer
- Laragon / Apache / MySQL

## Setup Instructions
1. Clone or place the project in your Laragon `www` directory (`C:\laragon\www\mini_capstone`).
2. Copy `.env.example` to `.env` and configure your database credentials.
3. Run composer install:
   ```bash
   composer install
   ```
4. Set your Laragon Virtual Host document root to point to the `public/` directory (`http://mini-capstone.test`).
